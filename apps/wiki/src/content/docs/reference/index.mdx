Common options are [capability-based](/reference/configuration/#global-options): argument-driven
commands broadly support JSON, prompt controls appear only on leaves that may prompt, and scope
flags appear only where declared. Mutating commands expose `--dry-run` where a preview is
meaningful, and destructive replacement always requires explicit intent beyond a generic
confirmation.

The explorer is progressively enhanced: its complete linked command list is present in the static HTML, while React adds text and category filtering when JavaScript is available.
